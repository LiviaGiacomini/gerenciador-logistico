# Gerenciador Logístico

## Sobre o projeto

O Gerenciador Logístico é um sistema web desenvolvido como projeto acadêmico da disciplina Fundamentos de Programação para Internet, da UNIPAR EAD.

O sistema permite cadastrar e editar produtos, endereços e transportadores, além de registrar fretes com múltiplos produtos e gerar relatórios por data.

## Funcionalidades

- Cadastro, listagem e edição de produtos.
- Cadastro, listagem e edição de endereços de origem e destino.
- Cadastro, listagem e edição de transportadores.
- Registro de fretes com múltiplos produtos e suas quantidades.
- Associação entre fretes, produtos, endereços e transportadores.
- Consulta de relatórios de fretes por data.
- Exportação de relatórios em CSV.

## Tecnologias utilizadas

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- XAMPP
- Git e GitHub

## Como executar o projeto

1. Instale o XAMPP.
2. Inicie os serviços Apache e MySQL.
3. Coloque a pasta `gerenciador_logistico` dentro de `C:\xampp\htdocs`.
4. Crie o banco de dados `gerenciador_logistico` no phpMyAdmin.
5. Crie as tabelas necessárias e seus relacionamentos.
6. Confira as configurações de conexão no arquivo `conexao.php`.
7. Acesse `http://localhost/gerenciador_logistico/`.
